# CampusEats — заказ еды в столовой колледжа

Этап 3 (Implementation): сервер с REST API + веб-интерфейс (адаптирован под телефон).

**Демо-версия:** файл `index.html` в корне проекта — открывается двойным кликом в браузере,
работает без сервера и без входа (роль Студент / Повар / Админ переключается вверху).

## Что умеет
- Регистрация и вход (пароли хешируются bcrypt, авторизация по JWT-токену).
- Меню с поиском и фильтром по категориям.
- Корзина: изменение количества, выбор перемены для самовывоза, оплата с баланса.
- Exception flow: если блюдо закончилось во время оформления — предупреждение и предложение замены из той же категории; если не хватает денег — сообщение с суммой.
- Мои заказы: статус заказа обновляется сам (каждые 5 секунд) и QR-код для получения.
- Кухня (повар/админ): список активных заказов и смена статуса «Принят → Готовится → Готов к выдаче → Выдан».
- Управление (админ): цена и наличие блюд, добавление блюд, пополнение баланса студента.

## Технологии
| Часть | Что используется |
|---|---|
| Бэкенд | Python 3.10+, FastAPI, SQLAlchemy (ORM) |
| База данных | SQLite по умолчанию, PostgreSQL через переменную `DATABASE_URL` |
| Авторизация | bcrypt + JWT |
| Фронтенд | HTML, CSS, JavaScript (без фреймворков), qrcode.js |
| Тесты | pytest |

## Запуск (Windows)
```bat
cd campuseats
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```
Открыть в браузере: http://127.0.0.1:8000
Документация API (Swagger): http://127.0.0.1:8000/docs

Открыть с телефона: телефон и ноутбук в одной Wi-Fi сети, запустить
`uvicorn backend.main:app --host 0.0.0.0` и открыть на телефоне `http://<IP ноутбука>:8000`.

## API
| Метод | Адрес | Кто | Что делает |
|---|---|---|---|
| POST | /api/auth/register | все | Регистрация студента |
| POST | /api/auth/login | все | Вход, выдаёт JWT |
| GET | /api/me | вошедший | Данные и баланс пользователя |
| GET | /api/dishes?category= | все | Меню, фильтр по категории |
| POST | /api/dishes | админ | Добавить блюдо |
| PATCH | /api/dishes/{id} | повар, админ | Цена / наличие блюда |
| POST | /api/orders | вошедший | Оформить заказ (проверка наличия и баланса, списание) |
| GET | /api/orders/my | вошедший | Мои заказы |
| GET | /api/orders | повар, админ | Активные заказы кухни |
| PATCH | /api/orders/{id}/status | повар, админ | Сменить статус заказа |
| POST | /api/admin/topup | админ | Пополнить баланс по email |
